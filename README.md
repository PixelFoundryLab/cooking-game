Golden Ladle Kitchen is a complete, original 2D cooking game that runs offline in a desktop browser. Take orders from the board, chop ingredients, cook on the stove, and serve dishes against the clock in a 3-minute shift.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
